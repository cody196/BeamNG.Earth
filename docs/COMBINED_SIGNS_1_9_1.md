# Combined signs for 1.9.1 beta

Branch: `port/combined-signs-1.9.1`, based on stock 1.9.1-beta commit
`e1c72abf`. The 1.9.1 world-generation, cached-data and teleport fixes remain
in place. This port adds the sign features from the saved 1.9.0 modified copy.

- **State welcome signs:** 49 state-specific faces, border detection, placement,
  streaming, artwork sources and tests. Includes the corrected vertical texture
  orientation for rectangular and shaped boards.
- **Interstate and US Highway shields:** already included in 1.9.1. The
  `legacyshields`, `routeindex`, `routemarkers`, `routerepeaters`, `routeshields`
  and `highwaysigns` modules match the donor byte for byte and are retained.
- **Exit sign heights:** compact content-sized panels and support counts were
  already present. The missing sampled-road-elevation fix from donor commit
  `fbc13dac` is ported. It prevents the anchor plane's placeholder height from
  making poles excessively tall on low terrain or far from the anchor, while
  preserving clearance beside raised roads.
- **Custom update protection:** the executable embeds
  `BUILD_VARIANT=combined-signs-1.9.1`. It keeps staged upstream releases from
  replacing this custom build and directs users to install matching custom
  updates manually. The base game/client version remains `1.9.1-beta`.

## Install

Close BeamNG/BeamMP and the Earth app, then launch
`BeamNG.Earth-1.9.1-beta-combined-signs.exe` to install the matching mod.
For BeamMP, install the matching server ZIP's `Resources` folder using its
included README and restart the server. Every player needs the combined EXE:
welcome and shield geometry is generated by each player's local world server.
Enable **Highway Signs** in the mod settings. Cache deletion is not required.

## Validation and rebuilding

Both sampled-height regression tests failed on stock 1.9.1 before the fix.
The migrated checks cover low terrain, distant anchors, raised roads, compact
panels, route-shield placement, streaming, all 49 exported welcome faces,
custom updates, packaging, and the BeamMP/client lifecycle.

Build both distributions with the same custom variant:

```text
python tools/build_app.py --build-variant combined-signs-1.9.1 --out dist/combined-signs
python tools/package.py --build-variant combined-signs-1.9.1 --beammp --out dist/combined-signs
```

The build tools name outputs using the base version; the delivered artifacts
add `-combined-signs` to their filenames. The artifact report records checksums,
test results, module and asset checks, and isolated startup validation.
Live in-game appearance has not been verified for this combined build.
